# Project Continuity

## Project
Munjed Alsaied personal portfolio.

## Goal
Create a high-end professional portfolio that presents Munjed as a full-stack developer, SaaS builder, digital systems architect, and public-sector digital transformation practitioner.

## Visual Direction
- Institutional, editorial, engineering-oriented.
- Neutral warm background, charcoal typography, restrained dark-red accent.
- No neon purple/blue gradients.
- No glowing AI-style visual language.
- No fake skill percentages or generic startup copy.
- Strong typography, whitespace, grid, real screenshots, diagrams, and case-study evidence.

## Primary Audience
- Employers in the Netherlands and Gulf region.
- Government/public-sector decision makers.
- Companies seeking SaaS, automation, CRM/ERP, infrastructure, or digital transformation work.

## Portfolio Structure
1. Home / positioning.
2. Selected Work.
3. Public Sector & Government Systems.
4. Individual case studies.
5. Profile / experience.
6. Technical capabilities.
7. Contact / GitHub / LinkedIn.

## Priority Case Studies
- Dummar Digital Transformation Platform.
- Government Agriculture Digital Project.
- AqarFlow CRM.
- ZZPers Hub.
- Commerce Platform.
- Solar Agro Tree.
- MHM IT systems/infrastructure work.

## Case Study Standard
Each major project should eventually contain:
- Context / problem.
- User or operational need.
- Munjed's role.
- Architecture.
- Key product decisions.
- Screenshots or diagrams.
- Technical stack.
- Constraints and trade-offs.
- Result / current status.
- Public repository or live demo only when appropriate.

## Public-Sector Safety
Do not publish confidential data, credentials, internal network details, private citizen information, sensitive operational data, or security-relevant implementation details. Public-sector projects should show architecture and outcomes only at a professionally safe level.
